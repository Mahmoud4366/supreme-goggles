# 🥽 Supreme Goggles

A tiny demo Android app, built fast just to see how it turns out. 🚀

یه اپ اندرویدی نمونه و ساده — سریع ساخته شد، فقط برای اینکه ببینی چطور میشه. 😄

## ✨ چی داره؟

- یه صفحه اصلی با یه متن و یه دکمه
- با زدن دکمه، متن عوض میشه ✅
- آیکون اپ (عینک 😎)

## 🛠️ تکنولوژی‌ها

- **Kotlin**
- **ViewBinding**
- **Material 3**
- minSdk 26 / targetSdk 34

## 📂 ساختار پروژه

```
supreme-goggles/
├── app/
│   ├── build.gradle.kts
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── java/com/example/supremegoggles/MainActivity.kt
│       └── res/
│           ├── layout/activity_main.xml
│           ├── values/ (strings, colors, themes)
│           └── drawable/ + mipmap-anydpi-v26/ (app icon)
├── build.gradle.kts
├── settings.gradle.kts
└── gradle.properties
```

## ▶️ اجرا

1. پروژه رو توی **Android Studio** باز کن (Open)
2. بذار Gradle Sync تموم بشه (اینترنت لازمه)
3. Run رو بزن ▶️
